# QiMenGFun 奇門吉方

可安裝、離線、本機優先的實景奇門時空羅盤 PWA。介面為臺灣繁體中文。

> **重要**：本產品為傳統文化參考，不是科學驗證的預測或物理能量量測；不承諾求財、健康、投資等結果。

## 功能現況（v0.1.0-preview）

- **時家轉盤拆補**：完整排盤（`hour-zhuan-chaibu-v1`），中五寄坤、子初 23:00 換日、實際交節改節氣。通過 5 組來源完整盤驗證（含 2024-12-25 陽遁四局、2026-07-15 陰遁五局逐宮比對）。
- **刻家**：十分鐘 12 刻**時間索引**可用；正式排盤一律回傳 `unverified`，UI 顯示「刻家規則尚待驗證」，不產生假吉方、不保存假盤。此為發布阻斷關卡。
- **分析**：八門／九星／八神／旬空／驛馬與事件取用神象意；進階格局（門迫、擊刑、入墓、伏吟、反吟、旺衰、干加臨）未驗證，明確不支援。雙盤交集為產品自訂規則，非傳統定律。
- **五大分頁**：羅盤、分析、時光、紀錄、工具。
- **本機優先**：無帳號、後端、廣告、分析 SDK；相機畫面、位置、照片、紀錄皆不離機。
- **PWA**：manifest、icon 192/512/maskable、Service Worker precache；首次完整快取後可離線。

## 使用方法

1. 首次歡迎頁可選擇性授權相機與方向；拒絕仍可使用純盤。
2. 上方資訊列點開可看公曆、四柱、時家／刻家各自局數、時間基準、修正量、方法版本與有效時間。
3. 點宮位看浮動卡，再展開底部詳細面板；點太極看中宮。
4. 底部時間軸可拖曳、播放（1×/10×/60×/600×）、正反向、NOW 回即時。外圈拖曳映射 120 分鐘。
5. 分析頁選事件、看九宮（南上北下）與規則依據；可複製 AI 解盤資料（先預覽、預設排除個資、不自動送出）。
6. 時光頁可指定日期時間、切換真太陽時（需經度／GPS）、看熱力圖與擇時掃描。
7. 紀錄頁拍照快照、查看、分享、刪除、ZIP 匯出。第一版無匯入還原。

## 時間基準

- 預設：裝置當地民用鐘面時間（含 DST），顯示 UTC offset。
- 可選：真太陽時 = UTC 分鐘 + 4×經度（東正西負）+ NOAA 均時差，正規化日期；**不移動天文交節瞬間**。無效經度不宣稱真太陽時。
- 節氣：tyme4ts 1.5.6（MIT）精確交節 UTC 時刻；鎖版錨點 2026-01-05 16:23:10 UTC+8 小寒。
- 干支日：子初 23:00 換日；年干立春換年；月干支十二節換月。
- 支援範圍：**1900–2100**（僅發布已驗證範圍）。

## 資料與隱私

- `localStorage qimengfun.v1`：設定、人物索引。
- `IndexedDB qimengfun-v1`：人物、records、photos（Blob）。
- 資料可能因系統清除而遺失，請定期從紀錄頁匯出 ZIP。
- 外部 AI 僅在使用者主動按「複製」後由使用者自行貼上；绝不自動送出。

## 開發

```bash
npm ci
npm test          # domain 單元測試（含來源盤驗證）
npm run test:layout   # 真瀏覽器 RWD 檢查（需本機 Edge/Chrome）
npm run build
npm run preview
```

部署至 GitHub Pages `/QiMenGFun/`。CI 見 `.github/workflows/deploy.yml`。
